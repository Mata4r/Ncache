# Guide for Ncache

This folder contains guides for using and contributing to Ncache (a Python network scanning script inspired by Scapy).

## Contents

- Getting started
- Usage
- Contributing

## Getting started

1. Install dependencies: `pip install -r requirements.txt` (if present).
2. Run the scanner: `python ncache.py` (replace with actual entrypoint if different).

## Contributing

Contributions are welcome — open an issue or a pull request with improvements to the guides or code.
